# Wave 3.75 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the 5 findings recorded in `docs/optimization-master-plan.md`'s
Wave 3.75 section (W1–W5) — small, independent, mechanical cleanups
discovered during a fresh audit. None require design judgment; each is a
verified, scoped fix.

**Architecture:** No new components. Each task edits 1–3 existing files in
place. No shared files between tasks — safe to run as independent subagent
dispatches.

## Global Constraints

- Bump the patch version in **both** `package.json` and
  `config/settings_schema.json` on every push (`CLAUDE.md`).
- No `!important` in CSS.
- No visual regression: every fix must render identically to today, in both
  light and dark mode where applicable. These are lint/cleanup fixes, not
  feature changes.
- Run `npx shopify theme check` after each task and confirm the specific
  offense(s) the task targets are gone, with no new offenses introduced.
- No automated test harness exists for Liquid in this repo (per prior wave
  plans). Verification is `npx shopify theme check` plus manual reasoning
  about rendered output from the diff — there is no local dev server
  reachable from this environment, and no browser preview step is required
  for these fixes, since none touches layout, only literal values and
  dead-code/defer changes. Note this as the accepted verification method in
  each task's self-review, matching this project's established practice.
- Commit after each task.
